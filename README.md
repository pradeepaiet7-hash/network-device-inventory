# Network Device Inventory

A simple browser-based Network Device Inventory for IT/Network Security administration.

## Categories
- Firewall: Sophos XGS 88, WatchGuard M290, FortiGate
- Switches: D-Link, Cisco, Aruba
- Wireless: Aruba AP-505, Sophos AP
- VPN: Sophos VPN, WatchGuard VPN, IPsec tunnels

## Features
- Dashboard with device counts
- Add, edit and delete devices
- Search and category filtering
- Device location, IP, serial number and status
- Password type/status field (do not store actual passwords)
- Browser local storage for a simple GitHub Pages demo
- Responsive interface

## Run
Open `index.html` in a browser.

## GitHub
Upload all files to a GitHub repository. For a public/private repository, use:
`index.html`, `style.css`, `app.js`

For sensitive production data, use a backend/database and do not commit credentials, VPN keys, passwords or secrets.
